# Data Science Repository

## Configurations First Steps (with VScode)

1. Install Visual Studio Code
2. Access Extensions in the left side bar and search for Python and Jupyter Notebook  
2. You have to install Python Extensions first in VScode: https://marketplace.visualstudio.com/items?itemName=ms-python.python
3. Then, you can install Jupyter Notebook Extensions in VScode: https://marketplace.visualstudio.com/items?itemName=ms-toolsai.jupyter 

### Docs for instruction:
- https://code.visualstudio.com/docs/datascience/jupyter-notebooks
- https://code.visualstudio.com/docs/languages/python


### Obs
You have to install Python's Extension first for Jupyter Notebook enviroment, when I installed Jupyter Notebook extension (using linux OS), VScode asked me to install kernels, I pressed yes and everything worked.
